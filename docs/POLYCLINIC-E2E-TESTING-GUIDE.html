1. System architecture

Local stack: Angular UI on port 4200, API Gateway on 9090, polyclinic microservices on 8092–8098.

UI talks to all APIs through the gateway. Clinical flows use doctor, appointment, queue, and order-service sales-admin.

3. One-time local setup

3.1 Start Docker services

cd D:\sugamFlow
powershell -NoProfile -ExecutionPolicy Bypass -File .\start-local.ps1 -EnvFile .env.local

Includes: doctor-service (8092), appointment-service (8093), queue-management-service (8098), gateway (9090), auth, account, user, order, product, stock.

6. 30-minute smoke test (one patient)

  1. Add patient Test Patient OPD at /users.
  2. Ensure doctor seeded or invited + doctordb profile.
  3. Reception: walk-in + token.
  4. Doctor: begin consult → save → complete visit.
  5. Pharmacy: prescription → save → Create Bill.
  6. Orders: verify bill; Stock: verify quantity.
  7. (Optional) Postman: lab order for same customer/consultation.
  8. Owner dashboard: refresh stats.

8. Troubleshooting

SymptomFix
Doctor dropdown emptyRun seed-trust-medi-01-doctors.sql; verify doctordb exists
404 on doctor/appointment/queueRestart ng serve; check services on 8092–8098
Staff invite auth timeoutRestart account-service + auth-service
Begin consultation forbiddenRebuild queue-management-service; grant MANAGE_CONSULTATIONS or MANAGE_ORDERS; re-login
No products for Rx linesImport medicines — Products tab hidden for POLYCLINIC
Prescription save JSON errorRestart order-service (EntityGraph fix on items)
Invalid login after startupWait ~1 min for auth/gateway/Postgres
