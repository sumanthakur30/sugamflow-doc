Field Force Workspace — Quick steps

Daily workflow
  1. Save lead (prospect) — not a shop registration.
  2. Select lead → log VISIT / DEMO / FOLLOWUP.
  3. KYC + subscription → Complete conversion.
  4. Owner gets invite email; shop activates after admin approval.

Do not use legacy “shop registration” for new prospects.

Lead statuses

StatusMeaning
NEW / CONTACTEDEarly pipeline
INTERESTED / FOLLOWUPActive follow-up
DEMO_GIVEN / NEGOTIATIONClose to conversion
CONVERTEDShop created
