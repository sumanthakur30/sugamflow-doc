# SugamFlow — Pathology Lab

**Client overview & industry comparison**  
**Business type:** `PATH_LAB` (Diagnostics & sample-to-report)  
**Entity label:** Patients  
**Document version:** 1.0 · **June 2026**

---

## Executive summary

**SugamFlow** is a cloud-based operations platform for Indian SMBs. **Pathology Lab** (PATH_LAB) Standalone pathology lab profile with sample worklist, test booking, report publishing, and automatic receipt of referrals from sibling polyclinic shops in the same tenant.

---

## Who is this for?

| Fit | Examples |
|-----|----------|
| **Standalone path labs** | Walk-in & referred patients |
| **Clinic-attached labs** | TRUST-MEDI-PATH pattern |
| **Home-collection labs** | Booking + sample tracking |
| **Multi-collection centres** | One lab, many sample points (roadmap) |

**Typical users:** Owner, counter staff, doctor/reception (healthcare).

---

## Daily operations covered

| Area | What SugamFlow does |
|------|---------------------|
| **Sample worklist** | Collect → accept/reject accession → process → report |
| **Walk-in & home-collection test booking** | Walk-in & home-collection test booking (department from catalog category) |
| **Lab report entry & PDF release** | Results with critical/delta flags, pathologist e-sign, PDF release |
| **Tenant-wide lab orders from polyclinic referrals** | Tenant-wide lab orders from polyclinic referrals |
| **Test catalog & lab billing** | Test catalog & lab billing with GST |
| **Patient master (shared** | Patient master (shared with clinic network) |
| **Barcode** | Barcode / sample tracking on worklist |
| **Dashboard KPIs for lab owner** | TAT (median / overdue), accession queue, critical results |

**Also included:**
- Receives polyclinic referrals with consultationId
- No retail product catalog—lab-focused UI
