## Executive summary

**SugamFlow** is a cloud-based operations platform for Indian SMBs. **Wholesale / B2B** (WHOLESALE) B2B wholesale profile with buyer-centric labels, volume-oriented billing, credit/dues tracking, and procurement workflows for distributors and bulk traders.

### Barcode billing — what “Basic (scan + Enter)” means

| **Included today** | **Not yet (full POS parity)** |
|--------------------|-------------------------------|
| Barcode on product catalog; API lookup per shop | Dedicated cashier-only POS screen |
| **Scan barcode** field on bill—USB gun or keyboard + **Enter** | Weighing-scale / grocery embedded barcodes |
| Adds line or **merges qty** when same SKU scanned again | Barcode label printer integration |
| Works in counter mode; auto-parts also has OEM search | Scan beep, hardware drivers, offline scan cache |

*Products must have barcodes loaded; missing/unknown codes show an error at scan time.*
